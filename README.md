# AI Writing Assistant untuk Konten Lokal

## 🚀 Fitur Utama
- Generator konten dengan nuansa Indonesia
- Template untuk berbagai jenis konten
- Database istilah lokal
- API RESTful backend

## 🔧 Instalasi
1. Clone repository
2. `cd backend && npm install`
3. `cd frontend && npm install`
4. `npm run dev` di kedua folder
